# Agent Workflow Audit

你已经有一个 Agent 想法、prototype，或一套每天重复的人工流程，但不知道下一步该先修哪里吗？

**Agent Workflow Audit（Agent 工作流程健康检查）** 会和你一起把流程摊开来看：它要帮谁、什么叫成功、哪里可能出错，以及哪些动作一定要先问人。这是固定范围的付费审查，不是大型开发项目。

## 这项服务适合谁？

适合已经有以下其中一项的团队或公司：

- 一个可以演示的 Agent prototype。
- 一套想交给 Agent 协助的人工流程。
- 一个已经在跑，但常常失败、太贵或很难检查的 Agent workflow。

如果你目前只有“想用 AI 做点事情”，还没有用户、流程或预期成果，先用这份免费学习地图找方向会更适合。

## 你要先提供什么？

只要提供不含机密的简短说明：

1. 谁会使用这套流程。
2. 现在怎么完成这件事，并列出三个常见失败。
3. 你最想解决的问题。
4. 你希望最后看到什么成果。
5. 数据是否包含个人信息、公司内部数据或其他敏感内容。
6. 可以接受的预算与希望完成的时间。

第一次来信不要附 API key、密码、客户名单、未公开代码或真实客户数据。

## 你会拿到什么？

Audit 完成后会交付五项内容：

1. **问题／成果契约**：用简单句子写清楚要帮谁、解决什么，以及怎样算成功。
2. **20 个初始 Eval 案例**：把正常、模糊与容易失败的情况整理成第一组可重跑的检查题。
3. **权限与人工批准图**：标出 Agent 可以自己做、必须先问人，以及不能做的动作。
4. **成本与可靠性风险**：找出可能让 token、工具费用、等待时间或错误失控的位置。
5. **下一步建议**：依重要程度排列先修、后修与暂时不要做的事情。

这 20 个案例是可继续扩充的起点，不等于完整的 production Eval suite。

## 这项服务不包含什么？

- 不包含完整 Agent、网站、API 或 SaaS 的开发。
- 不包含渗透测试、法规审查或安全认证。
- 不保证模型每次都回答一样，也不保证 production 成效。
- 不会代替你的团队决定法律、医疗、财务或其他高风险事项。

如果 Audit 后双方都认为适合再往下做，会另外讨论新的范围；本次 Audit 不会自动变成长期合约。
