# Agent Workflow Audit

你已經有一個 Agent 想法、prototype，或一套每天重複的人工流程，但不知道下一步該先修哪裡嗎？

**Agent Workflow Audit（Agent 工作流程健檢）**會和你一起把流程攤開來看：它要幫誰、什麼叫成功、哪裡可能出錯，以及哪些動作一定要先問人。這是固定範圍的付費審查，不是大型開發專案。

## 這項服務適合誰？

適合已經有以下其中一項的團隊或公司：

- 一個可以展示的 Agent prototype。
- 一套想交給 Agent 協助的人工流程。
- 一個已經在跑，但常常失敗、太貴或很難檢查的 Agent workflow。

如果你目前只有「想用 AI 做點事情」，還沒有使用者、流程或預期成果，先用這份免費學習地圖找方向會更適合。

## 你要先提供什麼？

只要提供不含機密的簡短說明：

1. 誰會使用這套流程。
2. 現在怎麼完成這件事，並列出三個常見失敗。
3. 你最想解決的問題。
4. 你希望最後看到什麼成果。
5. 資料是否包含個資、公司內部資料或其他敏感內容。
6. 可以接受的預算與希望完成的時間。

第一次來信不要附 API key、密碼、客戶名單、未公開程式碼或真實客戶資料。

## 你會拿到什麼？

Audit 完成後會交付五項內容：

1. **問題／成果契約**：用簡單句子寫清楚要幫誰、解決什麼，以及怎樣算成功。
2. **20 個初始 Eval 案例**：把正常、模糊與容易失敗的情況整理成第一組可重跑的檢查題。
3. **權限與人工批准圖**：標出 Agent 可以自己做、必須先問人，以及不能做的動作。
4. **成本與可靠性風險**：找出可能讓 token、工具費用、等待時間或錯誤失控的位置。
5. **下一步建議**：依重要程度排列先修、後修與暫時不要做的事情。

這 20 個案例是可繼續擴充的起點，不等於完整 production Eval suite。

## 這項服務不包含什麼？

- 不包含完整 Agent、網站、API 或 SaaS 的開發。
- 不包含滲透測試、法規審查或資安認證。
- 不保證模型每次都回答一樣，也不保證 production 成效。
- 不會代替你的團隊決定法律、醫療、財務或其他高風險事項。

如果 Audit 後雙方都認為適合再往下做，會另外討論新的範圍；本次 Audit 不會自動變成長期合約。
